## ✨ Key Features

- **6 Conversion Modes** for every need:
  - 🚀 Default/Fast Copy (no re-encode, instant)
  - 💎 Best Quality (CRF 18 + high bitrate)
  - ⚡ Ultra-Fast Stream Copy
  - 🎨 High Quality Re-encode
  - 📦 Compressed (smaller files)
  - ⚖️ Balanced (perfect quality/size)

- **Advanced Tools**:
  - 🎵 Extract audio → MP3 (192/320kbps), AAC, FLAC (lossless)
  - 📐 Batch resize → 720p / 1080p / 1440p / 4K / Custom
  - 📝 Embed subtitles into MP4 (mov_text)
  - 🔗 Merge multiple videos (concat)
  - 💬 Extract subtitles (.srt)
  - 📊 Show media info (ffprobe-style)
  - 📈 Compare original vs converted sizes
  - 🧹 Clean all output folders

- UTF-8 console with **emojis, colors, progress bars, success/failure counters**
- Supports **MKV, AVI, FLV, MOV, WMV, WEBM, M4V**

## 📋 Requirements

- Windows 10/11
- [FFmpeg](https://ffmpeg.org/download.html) installed and added to PATH  
  Recommended build: https://github.com/BtbN/FFmpeg-Builds/releases (latest win64-gpl)

## 🚀 Quick Start

1. Download `converter.bat` (rename the script if needed)
2. Drop it into the folder with your video files
3. Double-click to run – enjoy the menu!
4. Outputs go into organized folders (e.g., `MP4_Best`, `Audio_FLAC`, etc.)
